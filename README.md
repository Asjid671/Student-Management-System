# Student-Management-System
The Student Management System is a robust console-based application developed in C++ to streamline and simplify academic record-keeping. It replaces manual paperwork by providing a structured, interactive menu-driven interface to manage student profiles, track attendance, and record academic performance efficiently.

✨ Key Features & Functionality

1. Add Student: Allows users to input new student details including unique Student ID, Full Name, Class, Section, and Address. Automatically initializes default marks and attendance.

2. Update Student: Easily modify existing student records (such as name or address) using their unique Student ID.

3. Search Student: Instantly look up individual student profiles to view their complete details, grades, and attendance status.

4. Delete Student: Remove outdated or incorrect student records dynamically while maintaining array integrity.

5. Record Attendance: Track daily student presence by marking them as "Present" or "Absent".

6. Enter & Update Marks: Assign and update academic scores for students.

7. Show All Records: Displays a formatted, comprehensive list of all registered students in the system.

🛠️ Tech Stack & Concepts Used

Programming Language: C++

Development Environment: Visual Studio / Code::Blocks

Core Programming Concepts:

Parallel Arrays for data storage (SIZE = 100)

Modular programming using Functions (void functions for each operation)

Control structures (while loops, switch-case menus, and if-else conditions)

Standard Input/Output streams (<iostream> and <string>)

🚀 How to Run the Project

Open Visual Studio or any C++ IDE.

Create a new .cpp file (e.g., Student-Management-Record.cpp).

Paste the source code into the file.

Build and Run the project (Ctrl + F5) to interact with the console menu!
